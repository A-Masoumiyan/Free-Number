# بررسی number4.im — ۲۰۲۶-۱۰-۲۱

منابع مستقیم بررسی‌شده:

- https://number4.im/page/rule — سایت صراحتاً خود را واسط پنل‌های خارجی معرفی می‌کند. شماره برای یک اپلیکیشن و دریافت یک‌بارهٔ کد ارائه می‌شود. نام پنل‌های بالادستی اعلام نشده است.
- https://number4.im/ — معرفی API اختصاصی برای اتصال وب‌سایت، اپلیکیشن و ربات؛ انتخاب سرویس، کشور، پرداخت و دریافت شماره.
- https://number4.im/app/telegram — نمایش کد داخل همان محیط، رزرو زمان‌دار و لغو سفارش در صورت نرسیدن کد؛ شرایط و زمان‌ها ممکن است تغییر کنند و باید از قرارداد API خوانده شوند.
- https://number4.im/page/ref — برنامهٔ همکاری در فروش با لینک معرفی. لینک افیلیت معادل دسترسی API نیست.

نتیجه: این سرویس یک گردآورندهٔ شماره‌های عمومی رایگان نیست؛ گردش کار خرید/رزرو شماره برای سرویس مشخص دارد. ارائه‌دهندهٔ بالادستی مشخص نشد و انتساب آن به SMS-Activate، OnlineSim یا هر سرویس دیگر بدون سند درست نیست.

برای اتصال واقعی به Free Number، مستندات رسمی API نمایندگی، کلید حساب و اعتبار مالی لازم است. کلید مشترک تجاری نباید داخل APK یا EXE منتشر شود؛ رابط باید به بک‌اند مالک برنامه وصل شود و بک‌اند عملیات موجودی کشور/سرویس، قیمت، رزرو، وضعیت پیام، لغو و پایان سفارش را طبق مستندات واقعی اجرا کند. نشانی یا قرارداد API حدس زده نشده و هیچ سفارش یا خریدی انجام نشده است.

پیاده‌سازی فعلی: فیلتر ساختار شماره، گزارش‌های دستی تلگرام و مشاهدهٔ تاریخ‌دار سابقه در بخش رایگان. این فیلترها شماره را به «معتبر قطعی برای تلگرام» تبدیل نمی‌کنند. بخش پولی تا دریافت مستندات و دسترسی واقعی متصل نشده است.
