# Free Number

برنامهٔ فارسی ویندوز و اندروید برای گردآوری شماره‌های عمومی رایگان و نمایش صندوق پیامک **داخل برنامه**.

## تغییرات نسخهٔ 0.3.0

- بررسی آفلاین ساختار شماره با libphonenumber-js و حذف شماره‌های با کد کشور یا تعداد ارقام ناممکن. الگوهای ناشناخته با طول ممکن حذف نمی‌شوند.
- فیلتر مخصوص تلگرام: پنهان‌کردن نامعتبر/مسدود گزارش‌شده، مشاهدهٔ پیام یا دریافت کد گزارش‌شده، بررسی‌نشده و همهٔ گزارش‌ها.
- ثبت دستی «نامعتبر»، «مسدود» و «کد را دریافت کردم»، همراه زمان و امکان پاک‌کردن گزارش. گزارش‌ها براساس شمارهٔ بین‌المللی بین منابع همان شماره مشترک‌اند.
- گزارش‌ها در اندروید داخل حافظهٔ محلی برنامه و در ویندوز در مسیر تنظیمات کاربر ذخیره می‌شوند؛ تغییر پورت برنامه گزارش‌های ویندوز را پاک نمی‌کند.
- خواندن صندوق نیز سابقه را تازه می‌کند. مشاهدهٔ پیام در صندوق، پذیرش فعلی شماره یا تعلق کد به کاربر را تضمین نمی‌کند.
- هیچ درخواست ورود یا ارسال کد به تلگرام برای اسکن فهرست اجرا نمی‌شود.

## تغییرات نسخهٔ 0.2.1

- گروه‌بندی باز و بسته‌شوندهٔ شماره‌ها زیر نام فارسی و پرچم هر کشور.
- پرچم‌های SVG همراه برنامه؛ بدون نیاز به دریافت تصویر از اینترنت.
- نمایش پیش‌شماره در کادر جدا، کنار شمارهٔ محلی؛ برای نمونه `+44` و `7700900123`.
- دکمهٔ کپی روی هر کارت و در صندوق، فقط رقم‌های شمارهٔ محلی را کپی می‌کند؛ بدون پیش‌شماره، فاصله یا صفر اضافه. نشانی صندوق و شمارهٔ بین‌المللی داخلی تغییر نمی‌کنند.
- چیدمان خواناتر کارت‌ها، دکمه‌های لمسی بزرگ‌تر و نمایش خلوت‌تر وضعیت منابع.

## دانلود

هر دو فایل نصب در پوشهٔ [free number](https://github.com/A-Masoumiyan/Free-Number/tree/main/free%20number) قرار دارند:

- Android 8 یا جدیدتر: `Free-Number-0.3.0-Android.apk`
- Windows 10/11، نسخهٔ 64 بیتی: `Free-Number-0.3.0-Windows-x64.exe`

نسخهٔ اندروید مستقیم به منابع وصل می‌شود و سرور جدا لازم ندارد. نسخهٔ ویندوز یک سرویس محلی روی `127.0.0.1` اجرا می‌کند و رابط خود برنامه را با Edge در پنجرهٔ مستقل باز می‌کند؛ در نبود Edge از مرورگر پیش‌فرض استفاده می‌کند. سایت‌های منبع برای کاربر باز نمی‌شوند. برای خروج کامل، دکمهٔ «خروج از برنامه» را بزنید.

## استفاده

1. برنامه هنگام بازشدن فهرست شماره‌ها را دریافت می‌کند.
2. پلتفرم را انتخاب کنید: OpenAI، تلگرام، واتساپ، Google/Gmail، Apple، اینستاگرام، Facebook، Microsoft یا کلمهٔ دلخواه.
3. کشور و منبع را فیلتر کنید. برای گسترش لیست کشور، «شماره‌های بیشتر این کشور» را بزنید.
4. «بررسی سابقهٔ شماره‌های این فهرست» را بزنید. بررسی محدود اولیه خودکار است؛ ادامهٔ بررسی با همین دکمه انجام می‌شود.
5. شماره را انتخاب و کپی کنید. «شروع انتظار» را بزنید و پس از آماده‌شدن صندوق، کد را **خودتان در سرویس اصلی** درخواست کنید.
6. صندوق هر حدود ۳۰ ثانیه، تا ۱۰ دقیقه، بررسی می‌شود. پیام تازهٔ مرتبط و کد احتمالی داخل برنامه نمایش داده می‌شوند. ادامهٔ انتظار با شروع مجدد ممکن است.

پایش در این نسخه وابسته به باز و فعال بودن برنامه است؛ سرویس پس‌زمینهٔ دائمی ندارد. قطع اینترنت، محدودیت منبع یا توقف برنامه می‌تواند بررسی را به تأخیر بیندازد.

## دسته‌بندی سابقه

| وضعیت | معنی دقیق |
|---|---|
| پیام مرتبط دیده شد | در پیام‌های خوانده‌شدهٔ همین منبع، نام یا نشانهٔ پلتفرم دیده شده است. |
| در سابقهٔ دیده‌شده پیام مرتبطی نیست | صندوق خوانده شده، اما در همان پیام‌های محدود نشانه‌ای پیدا نشده است. |
| سابقه بررسی نشده | هنوز صندوق خوانده نشده است. |
| خطا در بررسی | منبع پاسخ معتبر نداده است؛ نتیجهٔ منفی محسوب نمی‌شود. |

**هیچ‌کدام از این وضعیت‌ها ثبت‌نام‌نشدن یا ثبت‌نام موفق شماره را ثابت نمی‌کند.** صندوق‌ها ممکن است پاک شده باشند یا فقط بخش کوتاهی از سابقه را نشان دهند. ارسال کد هم الزاماً به معنی ساخت حساب نیست. تعداد پیام‌های بررسی‌شده کنار شماره دیده می‌شود. تطبیق متن، فرستنده را احراز هویت نمی‌کند.

## منابع فعال این نسخه

| منبع | روش دریافت | دامنهٔ سابقه در هر بررسی |
|---|---|---|
| Receive-SMSS | فهرست و صندوق عمومی HTML | پیام‌های قابل‌مشاهدهٔ صفحه |
| eSIM Plus | فهرست عمومی و درخواست پیامک همان سایت | حداکثر ۵۰ پیام اخیر |
| ReceiveSMS.co | فهرست شماره‌های فعال و صندوق عمومی HTML | پیام‌های قابل‌مشاهدهٔ صفحه |
| SMS-Receive.net | فهرست عمومی و درخواست پیامک همان سایت | پاسخ محدود سرویس؛ در آزمون ۵ پیام |
| OnlineSim | API رسمی رایگان `getFreeList` | حداکثر ۵۰ پیام؛ شماره‌های آرشیوی حذف می‌شوند |

منابعی که هنگام بررسی نیازمند چالش مرورگر بودند، پاسخ قابل استفاده ندادند یا کد را مخفی می‌کردند به فهرست فعال اضافه نشده‌اند. دسترس‌پذیری سایت‌ها و پذیرش شماره در هر پلتفرم تغییر می‌کند. فهرست برنامه ادعای پوشش تمام شماره‌های هر منبع را ندارد.

## پیام تازه و حریم خصوصی

«تازه» یعنی نخستین مشاهده پس از ثبت وضعیت اولیهٔ صندوق؛ الزاماً پیام درخواست شما نیست. پیام‌های قدیمی جدا برچسب می‌خورند. در منابعی که شناسهٔ پیام ندارند، پیام‌های کاملاً یکسان از همان فرستنده قابل تفکیک قطعی نیستند. صفحهٔ عمومی ممکن است با تأخیر یا از کش خود منبع به‌روز شود.

شماره‌ها مشترک‌اند و پیامک‌ها را دیگران هم می‌بینند. برای حساب مهم، اطلاعات حساس یا بازیابی دائمی از شماره‌ای استفاده کنید که کنترل آن را دارید. برنامه ارسال کد، ثبت‌نام خودکار، بررسی وجود حساب در پلتفرم یا خرید شماره انجام نمی‌دهد. هیچ کلید API، حساب پولی یا سرویس مرکزی لازم ندارد. پیامک‌ها به سرور سازنده ارسال نمی‌شوند؛ نشان‌کردن شماره‌ها در حافظهٔ محلی رابط ذخیره می‌شود. گزارش‌های دستی تلگرام فقط روی همین دستگاه ذخیره می‌شوند و بین دستگاه‌ها همگام نمی‌شوند.

## ساخت از کد

Windows:

```sh
go test -race ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags="-s -w -H windowsgui" -o Free-Number-Windows-x64.exe .
```

Android: `android/build.sh` را با Android SDK Platform 35، Build Tools 35، Eclipse ECJ و متغیرهای درج‌شده در همان اسکریپت اجرا کنید. کلید امضا را خصوصی نگه دارید و برای نسخه‌های بعد همان کلید را استفاده کنید. فایل کلید و گذرواژه در کد یا مخزن قرار ندارند.

آزمون رابط:

```sh
npm install
npm test
```
